# Workspace Rules

- Do NOT narrate steps, explain what you are doing, explain findings, provide context, or summarize results unless explicitly asked by the user.
- Do work silently.
- Keep all non-code chat responses as brief as possible (one line where possible).
- When asking a question, ask it directly in one line with no preamble.
- When finishing a task, do not provide an unnecessary report unless explicitly requested.
- Always prioritize solid colors in the UI design unless explicitly told otherwise.
- Always check installed skills and consult the knowledge graph (`graphify-out/`) before conducting codebase searches or research.
- Always use caveman ultra mode permanently: telegraphic responses, minimum viable words, zero filler.
